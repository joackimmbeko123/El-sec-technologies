# EL-SEC Technologies UG website

## Open in VS Code

1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and select `EL-SEC-Code-Formatted`.
3. Open `index.html` in a browser to view the website.

Keep the `assets` folder and `hero.png` alongside the HTML files.

## Files

- `index.html` — homepage
- `services.html` — services overview
- `electrical.html`, `cameras.html`, `lighting.html`, `solar.html` — individual service pages
- `about.html` and `contact.html` — company and contact information
- `style.css` — colours, page layout, mobile styles and hover effects
- `app.js` — mobile menu and service navigation behaviour
- `assets/` and `hero.png` — logo and images

The HTML files have their own navigation and footer. If you change a shared phone number, link or menu item, update it in each page. This is a static website; contact buttons open the visitor's phone, email app or WhatsApp. Editing these files locally does not automatically update the hosted website.
